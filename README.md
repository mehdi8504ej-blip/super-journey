# GrowGram — ربات رشد کانال و گروه تلگرام

ربات دوطرفه: کاربران یا **اعتبار می‌خرند** یا با **عضو شدن در کانال‌های دیگران اعتبار می‌گیرند** و با آن کانال خودشان را تبلیغ می‌کنند.

## نصب سریع
1. در @BotFather ربات بسازید و توکن را بردارید.
2. فایل `.env.example` را به `.env` کپی و پر کنید (توکن، آیدی ادمین، شماره کارت).
3. اجرا:
```
pip install -r requirements.txt
python bot.py
```
یا با داکر:
```
docker build -t growgram .
docker run -d --restart=always --env-file .env -v $(pwd)/data:/app/data growgram
```
روی سرور (systemd) هم می‌توانید `python bot.py` را به‌عنوان سرویس اجرا کنید.

## قیمت‌ها (در `config.py` → `PACKAGES`)
| بسته | قیمت (تومان) | اعتبار |
|---|---|---|
| ۱۰۰ عضو | 80,000 | 200 |
| ۵۰۰ عضو | 300,000 | 1,000 |
| ۱۰۰۰ عضو | 500,000 | 2,000 |
| ۵۰۰۰ عضو | 2,000,000 | 10,000 |

اگر منظورتان از قیمت‌ها مبلغ دیگری بود، فقط همین لیست را عوض کنید.

## اقتصاد اعتبار
- هر عضو شدن تأییدشده = **۱ اعتبار**؛ هر عضو جدید برای شما = **۲ اعتبار** (یعنی ۲ عضویت = ۱ عضو رایگان).
- هدیه ورود ۴ اعتبار، پاداش دعوت ۳ اعتبار (بعد از اولین عضویت دوست دعوت‌شده).
- همه‌ی مقادیر در `.env` یا `config.py` قابل تغییرند.

## قابلیت‌ها
- ثبت کانال/گروه (فقط مالک/ادمین، ربات باید ادمین باشد)
- کمپین با تعداد دلخواه، لغو و بازگشت اعتبار باقی‌مانده
- تأیید خودکار عضویت با `getChatMember`
- چک مجدد بعد از ۳ روز: اگر عضو خارج شده باشد، پاداش کسر و جای خالی دوباره باز می‌شود
- ضدتقلب: سقف روزانه، فاصله بین تسک‌ها، هر کاربر فقط یک‌بار از هر کانال، گزارش کاربران (۵ گزارش = توقف خودکار کمپین)
- دفتر کل اعتبار (هر تغییر موجودی ثبت می‌شود)
- خرید کارت‌به‌کارت: کاربر رسید می‌فرستد، ادمین با دکمه تأیید/رد می‌کند
- رفرال، پنل ادمین

## دستورات ادمین
`/admin` آمار و راهنما — `/addcredits ID عدد` — `/userinfo ID` — `/ban ID` `/unban ID` — `/pause ID` `/resume ID` (کمپین) — `/broadcast متن`

## نکات مهم
- هنگام افزودن کانال، ربات باید ادمین باشد (کانال خصوصی: دسترسی لینک دعوت).
- رشد تشویقی در منطقه‌ی خاکستری قوانین تلگرام است؛ وعده‌ی «عضو فعال» ندهید و محتوای کلاهبرداری/بزرگسال را مسدود کنید (`/pause`, `/ban`).
- برای شروع، چند کانال خودتان را کمپین کنید تا تسک‌ها خالی نباشد.
- بکاپ: فقط فایل `data/growgram.db` را کپی کنید.
- پرداخت آنلاین (زرین‌پال و ...) را می‌توان بعداً به‌جای کارت‌به‌کارت اضافه کرد؛ `approve_order` در `database.py` نقطه‌ی اتصال است.

## آپلود در گیت‌هاب
فایل `.env` (توکن) در `.gitignore` است و **هرگز** نباید آپلود شود. فقط `.env.example` در ریپو می‌ماند.
```
git init
git add .
git commit -m "GrowGram bot"
git branch -M main
git remote add origin https://github.com/USERNAME/growgram.git
git push -u origin main
```
قبل از push دستور `git status` را بزنید و مطمئن شوید `.env` در لیست نیست.

## اجرا روی سرور بعد از clone
```
git clone https://github.com/USERNAME/growgram.git && cd growgram
cp .env.example .env   # و مقادیر را پر کنید
docker compose up -d --build
```

## آیدی ادمین
ادمین باید با **آیدی عددی** تعریف شود (نه یوزرنیم). در ربات دستور `/myid` را بزنید، عدد را در `ADMIN_IDS` فایل `.env` بگذارید و ربات را دوباره اجرا کنید.
